# Trilhas de Matemática 📐

> Uma plataforma web interativa desenvolvida para facilitar o aprendizado de matemática através de trilhas de estudo estruturadas, lições dinâmicas e quizzes.

## 🚀 Demonstração
Acesse a aplicação em funcionamento através do link: [Trilhas de Matemática](https://trilhas-de-matematica.vercel.app/#/)

---

## 🛠️ Tecnologias Utilizadas
* **HTML5 / CSS3 / JavaScript:** Estrutura, estilização e lógica dinâmica da interface utilizando dados locais.
* **KaTeX:** Renderização rápida e elegante de fórmulas e expressões matemáticas.
* **Vercel:** Plataforma utilizada para o deploy e hospedagem contínua.

---

## ✨ Funcionalidades
* **Trilhas de Aprendizado:** Conteúdos organizados de forma progressiva por níveis e módulos temáticos.
* **Lições Interativas:** Textos explicativos combinados com formatação matemática precisa.
* **Sistema de Avaliação (Quiz):** Exercícios práticos integrados ao final das lições com validação de respostas e explicações.

---

## 📂 Estrutura dos Dados
Os dados do site, incluindo níveis, módulos, lições e as questões dos quizzes, estão organizados diretamente em um objeto estruturado dentro do código-fonte da aplicação, permitindo fácil gerenciamento estático.
